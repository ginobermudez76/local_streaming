# LanScreenShare (local_streaming)

Aplicación de transmisión y visualización de pantalla en tiempo real a través de redes locales (LAN) desarrollada en **C# (.NET 9.0)** y **Avalonia UI**.

## 📖 Documentación y Arquitectura

* Consulta [**`PROJECT_ROADMAP.md`**](PROJECT_ROADMAP.md) para:
  - Arquitectura detallada y stack tecnológico.
  - Hitos completados y siguientes pasos de desarrollo.
  - Diagrama de clases y contratos orientados a soporte multiplataforma (Windows, Linux, Android/iOS).

## 🚀 Ejecución rápida

```powershell
dotnet run --project .\LanScreenShare.Desktop
```
